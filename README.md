# 🎮 Pixel Arcade

**Pixel Arcade** is a browser-based mini-game website where users can play simple classic-style games directly in their browser.

This project was created to practice **HTML, CSS, and JavaScript** while building an interactive and responsive gaming website.

## 🎯 Website Goal

The goal of Pixel Arcade is to create a fun and easy-to-use gaming website where users can quickly find and play games without downloading anything or creating an account.

## 👥 Target Audience

Pixel Arcade is designed for:

- Students
- Teenagers
- Casual gamers
- People looking for quick browser games

## 🎮 Games

The website includes simple versions of:

- 🐦 Flappy Bird-style game
- 🐍 Snake
- 🦖 Dino Game

## ✨ Features

- 🎮 Play games directly in the browser
- 🔎 Search for games
- 🗂️ Filter games by category
- 🏆 Current score and high score
- 🔄 Restart game functionality
- 📖 Game instructions and controls
- 🌙 Dark/light mode
- 📱 Responsive desktop and mobile design
- 🔗 Easy navigation
- 📚 Credits and source information

## 📄 Website Pages

### Home

Introduces Pixel Arcade and highlights the available games.

### Games

Allows users to browse, search, filter, and select games to play.

### About

Explains the purpose of the Pixel Arcade project and how it was created.

### Credits

Provides information about game inspirations, sources, and other resources used.

## 🎨 Design

Pixel Arcade uses a **modern retro-arcade style**.

### Colors

- Dark gray / black
- Neon blue
- Neon purple
- Neon green

### Style

- Retro gaming atmosphere
- Clean and simple layout
- Glowing buttons
- Game cards
- Smooth hover effects
- Responsive design

## 💻 Technologies

### Frontend

- **HTML5** — Website structure
- **CSS3** — Styling, layout, animations, and responsive design
- **JavaScript** — Game logic and interactive features
- **HTML Canvas** — Game rendering
- **LocalStorage** — Saving high scores

### Backend

No backend is currently used.

### Python

Python is not currently required because Pixel Arcade is a frontend-only project.
